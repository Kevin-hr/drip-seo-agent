# 网红合作“不合作／红灯淘汰”判断标准

- **文档状态**：Active
- **版本**：1.0
- **生效日期**：2026-10-10
- **适用平台**：TikTok、Instagram、YouTube Shorts 及其他短视频平台
- **适用阶段**：候选发现、合作前审核、寄样前审核、付费前复核

## 1. 决策原则

“不合作／红灯淘汰”是合作审核中的硬性否决结果。

只要确认命中任意一项红灯条件，即使账号粉丝量、播放量或互动率优秀，也不得用流量分抵消风险。最终结论固定写为：

> **不合作／红灯淘汰**

不得通过隐瞒商品性质、模糊品牌关系、误导创作者或要求创作者作不真实声明来绕过红灯。

## 2. 最低审核证据

作出红灯结论前，至少完成以下检查：

1. 确认账号身份、主页简介、粉丝量和累计互动。
2. 按时间顺序检查最近 10 条公开内容；置顶旧视频不得冒充最近内容。
3. 同时检查标题、画面、口播、屏幕文字和评论号召，不得只看封面。
4. 记录每条内容的发布时间、播放、点赞、评论及可获得的分享数据。
5. 计算最近 10 条的总播放、平均播放、中位播放和可见互动率。
6. 标注内容类别、产品展示能力、商业合作痕迹及品牌安全风险。
7. 对关键否决项保留视频链接和简要证据，不以猜测代替证据。

建议的可见互动率计算方式：

```text
可见互动率 =（点赞 + 评论）÷ 播放量
```

如果分享数可获得，可另行计算包含分享的扩展互动率，并明确两种口径。

## 3. 红灯硬性否决条件

### R1. 核心立场或商品认知直接冲突

出现以下任一情况即淘汰：

- 创作者近期公开反对、嘲讽或贬低拟合作的商品类别、商业模式或目标消费者。
- 创作者把“拒绝某类商品”作为持续人设或重复内容模板。
- 合作必须依赖创作者隐藏真实立场、虚假背书或作误导性真实性声明。
- 创作者既有内容会使合作内容显得明显自相矛盾，容易引发粉丝质疑或公开翻车。

### R2. 严重品牌安全风险

出现以下任一情况即淘汰：

- 近期内容反复出现仇恨、歧视性称呼、骚扰、威胁或煽动攻击。
- 大量粗口或侮辱性表达已成为稳定人设，且与品牌调性明显不兼容。
- 频繁出现毒品、烟草、危险行为、露骨色情或其他平台高风险内容。
- 存在可验证的诈骗、恶意曝光合作方、勒索式加价或重大声誉争议。

单次轻微失误可进入人工复核；重复出现、成为固定表达方式或存在明显升级趋势时按红灯处理。

### R3. 法律、平台或广告合规风险不可接受

出现以下任一情况即淘汰：

- 合作内容需要作无法证明的正品、功效、收益或身份声明。
- 创作者拒绝必要的广告披露，或有反复删除披露标识的记录。
- 内容存在明显商标、版权、虚假宣传、未成年人保护或平台政策风险，且无法通过合法方案消除。
- 创作者要求使用误导性链接、假评价、刷量或其他不透明手段。

### R4. 数据真实性存在重大问题

出现以下任一情况即淘汰：

- 粉丝、点赞或评论呈现明显批量造假特征，且无法得到合理解释。
- 最近内容长期低播放，但报价仍以历史爆款或异常粉丝量为主要依据。
- 评论高度重复、与内容无关，或账号增长曲线存在无法解释的异常跳升。
- 身份、账号所有权或受众数据无法确认。

数据不足本身通常标记为“待补证”，但发现伪造或蓄意误导时直接红灯。

### R5. 受众根本不匹配

同时满足以下条件时淘汰：

- 有可靠证据显示主要受众国家、语言、年龄或消费场景与目标市场根本不匹配；并且
- 无法通过单独内容、平台选择或区域投放修正。

不得仅凭创作者本人所在地推断受众所在地。

### R6. 商业履约风险不可接受

出现以下任一情况即淘汰：

- 有可靠记录表明收款或收样后失联、拒绝交付、擅自删除内容或严重延期。
- 拒绝书面确认交付物、发布时间、内容保留期、使用权或必要披露。
- 报价、付款账户或合作身份频繁变化且无法核实。
- 明确拒绝提供基础效果数据，同时要求高额固定费用。

## 4. 红灯优先级

审核顺序固定为：

1. 核心立场／商品兼容性
2. 品牌安全
3. 法律与平台合规
4. 数据真实性
5. 受众匹配
6. 商业履约
7. 流量、互动和内容质量

前六项中的硬性否决不能被第七项的高分覆盖。

## 5. 非红灯但需要降级的情况

以下情况一般不单独触发红灯，可标记为“黄灯／小额测试”：

- 平均播放不错但波动极大。
- 只有少量内容与商品相关。
- 产品展示能力一般，但没有价值观冲突。
- 受众国家、年龄或购买力数据暂时缺失。
- 内容制作粗糙，但互动真实且品牌安全。
- 没有历史带货转化数据。

黄灯账号只允许低成本、可追踪、分阶段测试，不得直接按大额长期合作执行。

## 6. 标准输出格式

每次审核至少输出：

```text
账号：@[handle]
平台：
审核日期：YYYY-MM-DD
样本：最近 10 条公开视频
结论：不合作／红灯淘汰
命中规则：R1 / R2 / ...
关键证据：
- 视频链接 + 内容摘要
- 视频链接 + 内容摘要
流量概况：总播放 / 平均播放 / 中位播放 / 可见互动率
说明：高流量不能覆盖命中的硬性否决项。
```

## 7. 已归档判例：@5staryoungin

- **平台**：TikTok
- **审核日期**：2026-10-10
- **结论**：不合作／红灯淘汰
- **命中规则**：R1、R2

### 关键证据

1. 最近 10 条中有 4 条反复强调只穿正品、拒绝 fake，分别涉及 Designer、Rick Owens、BAPE 和 Chrome Hearts。这不是偶发措辞，而是重复使用的内容模板，构成明确的商品立场冲突。
2. 最近内容反复出现大量粗口、侮辱性或种族性称呼，品牌安全风险高。
3. 出现烟草／大麻关联话题，可能限制广告复用和平台投放。
4. 尽管最近 10 条总播放约 44.9 万、可见加权互动率约 10.1%，流量表现不能覆盖 R1 和 R2 的硬性否决。

### 判例说明

该案例用于确立以下规则：

> **当创作者的稳定公开立场与拟合作商品或商业模式直接冲突时，无论流量和互动表现多好，都应判定为“不合作／红灯淘汰”。**

### 商品语境边界

“反仿品／只支持正品”的公开立场，只有在拟合作商品为仿品、假货，或商品性质无法被诚实证明时才构成 R1 直接冲突。若 offer 是可验证正品或合法自有品牌，该立场本身不触发 R1；但仍须独立检查 R2–R6，不能因为商品语境兼容就忽略粗口、仇恨称呼、毒品关联或其他品牌安全证据。

不得为了通过审核而把未验证商品标记为正品，也不得向创作者隐瞒商品性质。
